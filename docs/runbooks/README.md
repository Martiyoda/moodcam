# Runbooks

Procedimientos practicos para ejecutar demos, pruebas y operaciones del proyecto.

## Disponibles

- `mvp-esp32-test.md`: prueba completa del MVP con HiveMQ, AI Bridge, simulador y ESP32.
- `simulated-calibration.md`: prueba del panel de calibracion sin ESP32 ni brazo.

## Regla

Un runbook debe explicar pasos concretos, comandos y resultado esperado.
